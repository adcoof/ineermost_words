# 心语 v1.7

> 更稳的回复，更长的记忆，还有一个能帮你动手的本地 Agent。

这次更新把「聊天」之外的能力补齐了：Agent 可以读写你授权的文件、执行命令、联网搜索、操作手机；角色记忆从一段摘要升级为「近期记忆 + 长期事实」；同时修掉了偶发空回复、记忆被错误内容覆盖、换 Key 后旧会话报错等一批日常问题。

---

## ✨ 本次亮点

- **本地 Agent 正式可用**：文件读写、格式转换、联网搜索、HTTP、Shizuku shell、无障碍读屏/点击
- **记忆 v2**：多会话共享 + 长期事实时间线 + 3 天近期记忆，记得住「去过关山」，也不会编造细节
- **输出稳定性**：空回复自动重试、长度截断识别、整包 JSON 兜底、错误一键重试
- **隐私默认收紧**：关闭 Android 系统备份与设备迁移，数据库不再被云备份带出应用沙盒
- **上下文可控**：聊天与 Agent 各自独立的 token 窗口，顶栏实时显示用量

## 🆕 新增

### 🤖 Agent

- 底部新增第 5 个 tab：Agent 会话列表与对话页，支持 Markdown 渲染
- 私有工作区 + 系统授权文件夹（SAF），可列出、读取、写入、重命名、移动、删除文件
- 常用转换：Markdown → HTML、CSV ↔ JSON、HTML → 纯文本、JPG/WebP/GIF/BMP → PNG
- 联网搜索：360 移动搜索优先，百度 / Bing / DuckDuckGo 逐级回退，结果带来源链接
- HTTP 请求：仅公网地址，拒绝 localhost / 私网，支持域名白名单
- 执行命令：Shizuku 授权后可运行 `sh` 命令（禁 `su`、输出截断、超时保护）
- 手机操作：开启无障碍后可读取屏幕文字、按文字点击控件
- 三种审批模式：每步确认 / 自动审查 / 全自动；设置页配置默认值，每个会话可单独覆盖
- 文件可一键保存到 `Download/心语Agent/`
- 上下文窗口与单轮工具步数可调；超预算时自动压缩历史并保留「更早对话摘要」
- 打开会话自动定位到最新消息

### 🧠 记忆

- 跨会话记忆升级：每个会话独立摘要水位线，不再因为切换会话漏记
- 长期事实：从对话中提取「事实 + 日期」，最多保留 240 条，可在记忆页长按删除
- 近期记忆默认保留 3 天细节；被问及更早的事只保留事实，不编造过程
- 记忆页三段式：角色记忆 / 长期记忆 / TA眼中的你，支持下拉刷新与 PNG / Word 导出
- 纯图片消息的图片概括也会进入记忆

### 💬 会话与界面

- 上下文用量 chip：聊天页顶栏显示百分比，点开查看系统/记忆/跨会话/历史/当前输入分类
- 空回复自动重试；失败后 SnackBar 提供「重试」
- 消息长按：复制文本、删除单条消息
- 聊天与 Agent 的窗口大小、Agent 单轮工具步数均可在设置中调整

## 🛠 改进

- 流式解析兼容更多返回形态：`delta.content` 数组、`reasoning_content`、`choices[0].text`、整包 JSON
- 推理内容与正文分离，避免「只返回推理」被当成空回复
- 角色提示词按 token 预算滑动取历史，替代固定 40 条
- 旧会话绑定的供应商被删除或 Key 为空时，自动回退当前默认供应商
- 数据库补充消息与会话查询索引，长会话加载更稳
- Agent 工具结果裁剪改为保留头尾，长输出不再只剩开头
- 错误提示从「只能关闭」变为可重试

## 🐞 修复

- 修复模型偶发返回空正文时留下空气泡的问题
- 修复记忆摘要把模型拒绝语（如 `high risk`）当正文写库、覆盖旧记忆的问题
- 修复 Android 上工作区路径经 symlink 后被误判「越出工作区」，导致写文件失败
- 修复 SAF 文件被误判为目录、移动/重命名时递归创建 `note.txt/note.txt/...` 的问题
- 修复 Agent 打开长会话停在顶部、看不到最新消息的问题
- 修复旧会话绑定的供应商被删除或 Key 为空时仍报 401 的问题（自动回退默认供应商）
- 修复 Markdown 原样显示、未渲染的问题

## ⬆️ 升级说明

- 直接覆盖安装即可，原有会话、角色、记忆会保留；数据库会自动迁移到 v12
- v1.7 起关闭系统自动备份与设备迁移；换机请使用应用内导出（后续版本会补齐整库备份）
- Agent 的文件权限、Shizuku、无障碍都需要你在系统/设置页手动授权，可随时撤销
- 卸载重装会丢失本地数据，升级请勿先卸载
- Android 8.0（minSdk 24）及以上

## ⚠️ 已知限制

- 联网搜索依赖第三方搜索结果页，部分网络环境可能被重置或超时；失败时会如实告知，不会编造结果
- Shizuku 需单独安装并启动 Shizuku 应用；无障碍需在系统设置中开启
- API Key 目前保存在本机数据库，尚未迁移到系统安全存储
- 发布包暂未使用正式签名（本项目不上架应用商店）
