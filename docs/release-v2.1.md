# 心语 v2.1 发布说明

> 版本：2.1.0+15（versionCode 15）\
> 数据库：schema v17（v16 自动升级）\
> 日期：2026-11-27

## 重点更新

### 完整角色档案

- 在原有 6 个 SillyTavern 核心字段之外，新增基础身份、外貌、背景、关系、语言风格、互动方式、创作者信息、卡内系统提示等档案分区。
- 编辑页改为「基础 / 档案 / 高级」三页签；核心字段保留 AI 改写，档案字段可手动完整编辑。
- 档案块按窗口 12%（300–1200 token）注入提示词；创作者信息不进入提示词，卡内系统提示与历史后置指令单独限长注入。
- 上下文用量弹层新增「角色档案」「卡内提示」分类。

### 角色卡导入导出

- 导入：SillyTavern V1 / V2 / V3 JSON 与 PNG（`chara` / `ccv3`），映射 `nickname / creator / tags / creator_notes / system_prompt / post_history_instructions / character_book`。
- 未识别的 `data` / 根字段与第三方 `extensions` 原样保留；导出时合并回去，不静默丢失。
- 世界书条目保存 `source_json`，书籍级元数据（name / scan_depth 等）单独保留；导出时按 ST 结构合并当前值与原文。
- 导出：V2 JSON、V3 JSON、PNG 角色卡（自动写入 `chara` + `ccv3` tEXt 块）；导出前展示心语专有数据损失清单。
- 默认写入 `extensions.xinyu` 承载完整档案，导回心语时自动回读；第三方软件可忽略。

### 版本快照

- 保存已有角色时自动快照旧状态；内容未变不重复写入；每角色最多 20 条。
- 版本页支持查看变更摘要、查看快照 JSON、恢复、删除；恢复前会把当前状态存为一条 `restore` 快照。
- 立绘不参与版本回滚（界面已说明）。

### 导航与资产

- 底部导航改为「聊天 / 工坊 / 资产 / 设置」。
- 工坊首页顶部为「AI 创作角色」卡片，下方为「我的角色」列表。
- 新增资产聚合页：桌宠模型、角色立绘、表情包、音色；桌宠从底栏移入资产页。

## 升级说明

- 建议使用覆盖安装（`adb install -r`），不要卸载，避免清空本地数据。
- 数据库从 v16 升级到 v17：只新增列与表（`characters.profile_json / extensions_json`、`lore_entries.source_json`、`character_versions`），不重建旧表。
- 旧角色升级后档案为空，原有 6 个字段、立绘、记忆、世界书保持不变；下次保存开始生成版本快照。
- v1.8 起通用 Agent 已移除；v2.1 不再包含 Agent、Shizuku、无障碍与文件/命令工具。
- 角色卡导出默认携带 `extensions.xinyu`；不需要时可在导出对话框关闭。

## 已知限制

- 档案字段暂无 AI 改写、诊断与多方案生成（计划 2.2）。
- 暂无自动保存、撤销/重做、字段搜索；版本快照不包含立绘。
- 世界书仍是角色内条目，尚无共享库/多角色多对多绑定（计划 2.3）。
- 资产页目前是入口聚合，没有统一资产表、多立绘/服装或角色-Live2D 绑定。
- PNG/JSON 导出已在自家导入器上往返验证；尚未用真实 SillyTavern/第三方阅读器做最终验收。
- 真机验收需覆盖：v16→v17 迁移、导入真实 V3 卡、编辑档案、聊天注入、导出 PNG 后重新导入、四栏导航与资产页。
