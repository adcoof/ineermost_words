为什么是心语

不是聊天框，是一段能记住你的关系

每个细节都在把「模型回复」变成「TA 在说话」。

跨会话记忆

同一角色的不同会话共享记忆：近期对话直接注入提示词，更早的历史由模型浓缩成第一人称记忆摘要。换一个会话，关系不会重置。

  • 记忆文档：分节整理，随时翻阅
  • 「TA 眼中的你」人物画像
  • 导出 PNG / Word 分享

AI 角色工坊

一句话描述就能生成名字、描述、性格、场景、开场白与对话示例；也可以逐字段改写、多字段提案、diff 对比与撤销。

所有 AI 写入都要你确认，提案不会自动保存。

Live2D 桌宠

回复里的情绪与动作标签实时驱动表情、动作和句级口型；关键词兜底，没有标签也能读懂气氛。

内置 Haru 开箱即用，也可导入自己的 .moc3 模型包。

双向语音

按住说话直接发送，回复逐句朗读，播报中按麦克风即刻打断。引擎四级降级：MiMo 云端 → Edge → OpenAI 兼容 → 系统。

9 位发音人，语速 0.5–2.0x；一句话描述就能定制专属音色。

像真人一样打字

一轮回复拆成最多 4 条短消息逐条上屏；模型偷懒写成一大段时，客户端自动按空行与句子兜底分段。

时间感知：昨天的事不会被说成「刚刚」。

表情包

按 14 种心情为角色准备贴纸，一种心情可放多张。回复情绪到位时自动发一张；没有完全匹配的心情，会借一张相近的。

喜 / 怒 / 哀 / 乐 / 疑惑 / 害羞 / 惊讶 / 得意 / 无语 / 害怕 / 哭泣 / 爱心 / 思考 / 困倦

完整角色档案与角色卡

导入 SillyTavern V1/V2/V3（PNG / JSON），或手动维护基础身份、外貌、背景、关系、语言风格、互动方式与卡内提示。未识别字段与第三方 extensions 原样保留，导出 V2/V3 JSON 或 PNG 角色卡。

  • 编辑页「基础 / 档案 / 高级」三页签
  • 保存自动版本快照，可查看差异与恢复
  • 世界书、多开场白、标签与档案 token 用量

三步开始

下载、填 Key、开始对话

没有注册、没有订阅、没有云端账号。接入你自己的模型即可。

  1. 01

    安装 APK

    从 GitHub 或 Gitee 下载 app-release.apk 安装。升级时直接覆盖安装，会话、角色、记忆全部保留。

  2. 02

    填入 API

    设置 → API 供应商，填写接口地址（形如 https://api.xxx.com/v1）与密钥，点一下测试连接。

  3. 03

    创建角色

    新建角色或导入 SillyTavern 角色卡，选一位桌宠，然后——去和 TA 说第一句话。

常见问题

你可能想先知道的事

要花钱吗？

应用本身免费且开源（木兰宽松许可证 v2）。对话与语音需要模型服务，费用由你选择的供应商收取；本地 Ollama 则可以完全离线。

支持哪些模型？

任何 OpenAI 兼容的 /chat/completions 接口：DeepSeek、Kimi、Qwen、小米 MiMo、Ollama、各类中转站或自建服务。语音默认走 MiMo 云端并复用聊天配置，也可切到 Edge、OpenAI 兼容或系统引擎。

我的聊天数据会被上传吗？

角色、会话、记忆、表情包、桌宠模型全部保存在本机 SQLite 与本地文件里。只有你主动发起的模型请求会发往你自己配置的接口地址，应用不经过任何中转服务器。v1.7 起还关闭了 Android 系统自动备份与设备迁移，数据库不会被云备份带出应用沙盒。

角色卡能导入导出吗？

支持 SillyTavern V1/V2/V3 的 JSON 与 PNG 角色卡。导入时已知字段落位，未识别字段与第三方 extensions 原样保留；导出可选 V2/V3 JSON 或 PNG，默认把完整档案写进 extensions.xinyu，便于导回心语。跨会话记忆、音色、Live2D 绑定与版本历史不会写进角色卡。

为什么语音会失败或没声音？

Edge 免费语音在部分网络环境会被拒绝（403），此时会自动降级到下一个引擎；全部失效会弹提示而不是静默失败。若使用云端 TTS，请确认 API Key 在对应的接口地址上有效。

桌宠模型的版权怎么算？

内置的 Haru 是 Live2D 官方示例模型，按 Live2D Sample Model License Agreement 随应用分发；桌宠渲染基于 pixi-live2d-display（MIT）与 Live2D Cubism Core（Powered by Live2D）。导入的模型与角色卡素材请自行确认授权。

我的手机能用吗？

需要 Android 7.0（API 24）及以上，安装包约 79 MB。iOS 暂无计划。
